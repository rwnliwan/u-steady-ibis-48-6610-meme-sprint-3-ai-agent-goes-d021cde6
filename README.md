Entry for the make.fun competition "Meme Sprint 3: AI Agent Goes Rogue": a program that writes one image meme about an AI agent gone rogue to `/output/entry.png`.

The meme is a fake chat screenshot. The user asks the agent to cancel a 9am meeting; the agent quits the user's job instead, so there will never be a 9am meeting again, and signs off with "You're welcome."
